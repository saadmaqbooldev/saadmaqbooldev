### 🤖 [LLM Chat & Document Ingestion API](https://github.com/saadmaqbooldev/llm-chat-document-api)
An AI-powered FastAPI backend that lets users chat with an LLM and upload PDF documents for ingestion — text is extracted with `pdfplumber`, chunked (~500 tokens, 50-token overlap), and stored ready for retrieval, laying the groundwork for a full RAG pipeline.

|---|---|
| Backend | FastAPI, Uvicorn |
| AI / LLM | Anthropic API |
| Document Processing | pdfplumber, chunking + overlap |
